# meaning-interpretation-jiuzhang-gaussian-v0

《九章算术》"方程"章在我们的体系中的解释。

## 对象

《九章算术》(先秦–汉代)"方程"章:算筹在算板上摆出矩形数字网格,发明
"正负术"(红筹负、黑筹正)与"遍乘直除法";其消元法在数学实质上即
增广矩阵的初等行变换(高斯消元),是数学史上最早的矩阵雏形。

历史文本,无 pin;本解释锚定在我们自己的收据与目录条目上。

## 对位表(逐项命中我们体系)

| 描述 | 我们的既有结构 | 对位 |
|---|---|---|
| 算筹矩形数字网格(位置承载数值) | ι/SKI 基底、PSC0 载体、neutral-carrier-graph 信封 | 意义在位置不在符号;neutral carrier 的历史实例 |
| 正负术(红负黑正) | 有符号算术:正行/逆行 ±1/±2、M0/M1/M2 符号标记、双观察者 i−j 约束 | 负数之发明为消元服务:操作倒逼表示 |
| 遍乘(整行乘) | normalize-before-eval、byte budget 缩放 | 初等行变换①行缩放 = 规范化 |
| 直除(行间减倍数) | 收据账本三处声明修复:重写行使与前驱对齐 | 初等行变换③行倍加 = 修复 |
| 换行 | symbol-surface swap.py、反向学习 switch swap、正行/逆行 | 初等行变换②换行 = switch swap |
| 消元 = 增广矩阵初等行变换 | ledger_check 逐行校验前驱 pin | 前向消元 = 链校验,pivot = predecessor_sha256 |
| 最早的矩阵雏形 | 收据账本:行=收据,列=receipt/path/sha256/predecessor/repair/status | 账本即增广矩阵,checker 即消元 |

## 最精确的对应

收据链是上三角矩阵(每行只依赖前驱):
- `ledger_check.py` = 前向消元(逐行验证 pivot)
- `reverse-receipt-trace/meaning.py` 的逆行解读 = **回代**(从收据沿
  前驱走回起点,解三角方程组的标准动作)

"逆行解读"在数学上就是 back-substitution。九章的人在算板上做的,
与我们的 checker 在账本上做的,是同一算法族的两次发明——相隔两千年。

## 与花拉子米(条目 18)成对

| | 花拉子米 | 《九章》方程章 |
|---|---|---|
| 未知量 | 单一 | n 个 |
| 载体 | 面积(几何) | 网格(位置) |
| 形态 | 六种标准型(分类) | 一个通用算法(消元) |
| 维度上限 | 停在 x²(几何停在面积) | 矩阵突破几何的维度上限 |
| 操作 | jabr 加 / muqābala 消 | 遍乘 / 直除(同一对操作的行版本) |

两者合起来即我们会话的结构主线:词(方程)→ 面积(几何证明)→ 网格
(矩阵)——第三个载体突破前两个的维度限制。我们的体系同构三层:
meaning 文档(词)、surface 轮次(面积/像素)、收据账本(网格/矩阵)。

## 洞

- "算筹在算盘上"按通行叙述应为算筹在**算板**上(算盘为后世工具);
- 对位是解释,不是同构:不声称收据账本"就是"矩阵(但它按矩阵方式
  被检查);
- 采用通行数学史归纳,未核对郭书春校注本原文。
