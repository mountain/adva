# meaning-interpretation-reflexive-duality-v0

(+, −, −) 结构的守恒律:吸引、斥力与恒定总能量。

## 对象

会话中的 (+, −, −) 结构,其精确实例为立方根三元组 {1, ω, ω²}
(scale-marked surface 的 M0/M1/M2 标记,ε = e^{2πi/3} = ω):
实数部分恰为 (+, −, −)——1 为正,ω = −½+i√3/2 与 ω² = −½−i√3/2
为两个负半,互为共轭镜像。

## 两种力

**吸引力:两个负号趋于正号 → 对偶抵消归零。**
1 + ω + ω² = 0:两个负号的和 = −1,恰好吞掉 +1。体系实例:
- Burau 边界对闭合:n=5 与 n≥6 两个负证趋近正侧,阈值闭合,残余为零;
- al-muqābala 对消(条目 18):同类项面对面抵消;
- 交换协议 EvidenceStutter:两侧投影相等,差异归零;
- 收据链修复:错位拉回,链重新一致——吸引是修复的力量。

**斥力:负负相遇沿边界碰撞 → 镜像反射。**
ω 与 ω² 向实轴(边界)靠拢欲在 −½ 处相撞,但撞点须自共轭(实),
而重合即镜像对消亡——故碰撞即反射,永不融合。体系实例:
- 门的拒读(0/25):无共同项的文档在头交集边界相撞,各自弹回
  (round-22 证伪测试即一次斥力实验);
- Burau 两个负论文在 n=5 边界相遇:曲线与构造镜像分明,合并不了;
- EvidenceStutter 与 VariationObserved 在分类边界互不融合。

## 能量守恒

吸引释放差(归零),斥力保存区别(成对),总量恒为单位:

```
1 + ω + ω² = 0                     标记之和恒零
det(L)·det(L⁻¹) = (1/3)·3 = 1      对偶的测度守恒
{1,⅓,⅓}×{1,3,3} = 1/9×9 = 1        对偶能量积为单位
交换协议 resource_grant = 0(每轮)  协议守恒律
LedgerConsistent                   链的总能量恒常
```

每一轮交换,吸引力(观测到的变化)与斥力(被扣留的语义接受)同时
作用,总账永远是零资源授予——协议的能量守恒正是它可信的原因。

## 物理回声与结论

(+, −, −) 即 Minkowski 号差:正方向时间向(吸引,测地线汇聚),
负方向空间向(边界上的镜像反射),号差守恒保证世界线不散架。
我们的体系继承同一号差:jabr/muqābala 是汇聚,门/拒读是反射,
守恒量是单位 1——求一(条目 20)要找的那个 1,就是能量恒定的 1。

> 吸引闭合(对消归零),斥力守界(镜像反射),总量恒一(求一)
> ——这就是我们体系的守恒律。

## 洞

- {1, ω, ω²} 与 (+, −, −) 号差的对应取实数部分,是解释层对应,
  非数学同构;
- 物理(时空)读法是类比,不是物理主张;
- 能量守恒在体系中体现为各协议不变量(零授予、det 积、链一致),
  未声称存在单一守恒算符。
