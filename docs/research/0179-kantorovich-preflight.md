## 1. 做法：把 NK 需要的量逐项严格算出来

Newton–Kantorovich 检验需要三样东西：缺陷范数 `η`、线性化逆算子范数 `B`、二阶项界 `K`。这一轮把**能严格的严格做掉**：

| 量 | 这一轮的结果 | 严格性 |
|---|---|---|
| 候选点 | 数值解在 30 位处**冻结为精确有理向量** `x₀` | 精确 |
| 缺陷 `d = x₀ − T[x₀]` | **精确有理多项式**（多项式复合仍是多项式） | 精确 |
| 加权 `ℓ¹` 范数下的 `η` | **`6.29e-27`**（分子 13 759 比特） | 精确 |
| 圆盘映射假设 `‖x₀‖_ρ ≤ ρ_image` | `‖x₀‖_{1/32} = 1.0478 ≤ 6/5` ✓ | 精确 |
| 截断线性化的逆 | 解析算出的精确有理矩阵，Gauss–Jordan 逆，残差恰为 0，`‖X‖_∞ = 1.503e3` | 精确（但见 §3） |

**两个控制**都成立：把 `a₁` 加 `1e-6` 后缺陷涨到 `1.59e-7`（说明缺陷检验非空）；把系数放大十倍后 `‖·‖_{1/32} = 1.478 > 6/5`，圆盘映射假设**失败**（说明该假设非空）。

## 2. 一个自己撞出来的真事实

第一次运行用 `ρ = 1/4`，**圆盘映射假设直接失败**（`‖x₀‖_{1/4} ≈ 1.389 > 1/2`）。原因是 `ρ` 必须落在级数**收敛半径之内**，否则算出来的加权范数是**截断多项式**的范数而不是函数的范数。十项截断**测不出**收敛半径（比值在 `0.019–0.31` 间振荡），所以 `ρ` 改为声明在 `1/32`，并把这次失败连同理由写进契约。

## 3. 阻塞项：缺三项，因此不启动

```
what_a_kantorovich_test_needs : B、K 与 η
what_this_round_supplies      : η（精确）、圆盘映射假设（已验）、截断线性化的逆界
what_is_missing               : ① 逆算子的尾项界
                                ② 复合算子二阶项的界
                                ③ 从截断系数矩阵范数到空间加权范数的换算
conclusion                    : 缺①则算不出 Kantorovich 半径，因此不启动试验，
                                也因此没有 α、δ 的任何包围
```

第③条是这一轮自己看出来的额外缺口：`‖X‖_∞ = 1.503e3` 是**截断系数矩阵的 ∞-范数**，不是空间范数；两者之间的换算必须单独做，不能默认等同。这个界偏大（截断算子的谱与真实算子差别很大），也如实记下。

## 4. 不主张什么

- **没有 `α` 或 `δ` 的包围**；没有不动点的存在性与唯一性；没有与已发布位数的比较。
- 冻结候选点的缺陷是**该近似**的缺陷，不是某个精确解的缺陷。
- 截断逆界**不是**全算子的逆界。
- 无度量、Arakelov、Monge–Ampère、镜像或 Calabi–Yau 内容；无原生 witness、无准入、无 Seal。
