## 0. 为什么做这个 frame

起点是一个模糊感觉：「Surreal 的序」与撕裂 / clock 的语言有关。模糊感觉不能被复核，
所以把它做成一次计算：拿那条九行判据去量 Conway 构造，看**哪个 clock 下降、哪个撕裂**。

**结论先写**：

> **感觉是对的，但落点要翻一下——Surreal 的"序"是不撕裂的那个 clock。
> 撕裂住在"生日 / 呈现日"里。**

---

## 1. 判据（引用，九行）

$$\text{clock 下降到状态}\iff q(h)=q(h')\ \Rightarrow\ c(h)=c(h')\quad\forall h,h'$$

**撕裂** $\iff$ 存在**见证对** $(h,h')$：$q$ 相同而 $c$ 不同。

判据只判定**给定的** clock 对**给定的**任务是否下降；不判定哪个 clock 是对的。

---

## 2. 这个 frame

| | 对象 |
|---|---|
| 历史 $H$ | **形式** $(L\mid R)$，其元素是生日更小的**数** |
| 状态 $q$ | 该形式**呈现的值**——simplicity 规则：区间 $(\max L,\ \min R)$ 中最简的那个数 |
| clock $c_1$ | **序**（由呈现自身解码，见 §3） |
| clock $c_2$ | **呈现日** $\mathrm{day}(L\mid R)=\max(\text{元素生日})+1$，空形式为 $0$ |
| clock $c_3$ | 第 $d$ 日类内的 **$d$ 位 L/R 地址** |

**形式是呈现，值是内容。** 关键是 $\mathrm{day}$ 是**呈现**的性质，不是**值**的性质——
TEAR 就从这里来。

例：$(\ \mid\ )=0$ 且 $(1\mid\ )=2$ 且 $(\ \mid 1)=0$——第三式与第一式**是同一个值 0，却在第 2 日**。

---

## 3. 序怎么解码（本次的实质在那一步）

不能拿值去定义序，否则就是"值的函数当然是值的函数"（我第一版正是这么错的，见 §10）。
所以这里写了**两个彼此独立的实现**：

1. **值**：`simplest(lo, hi)` —— 按 simplicity 规则直接实现（与"生日本身"独立）。
2. **数之间的序**：康威递归规则用在**规范形式**上，
   $x\le y \iff$ 没有 $x^L\ge y$ 且没有 $y^R\le x$。
   规范形式取"该数出生时所在的那个间隙"，递归在（生日之和）上严格递减 → 终止。
3. **形式之间的序**：**同一条规则，但用在任意呈现上**：
   $F\le G \iff$ 没有 $f^L\ge G$ 且没有 $g^R\le F$。
   **这个函数从不读 $F$、$G$ 的值**；元素是数，所以只有"数与数"的比较，走第 2 条。

然后交叉检查：第 2 条 vs `Fraction` 自然序、第 3 条 vs 第 2 条。三条互相独立。

## 4. 自检：构造本身的完整性

| 检查 | 结果 |
|---|---|
| 第 $d$ 日出生的数 = $2^d$（$d=0..3$） | $1,2,4,8$ ✓ |
| 生日 $\le3$ 的数共 $2^4-1=15$ | ✓ |
| 地址长度 $==$ 生日（每个数） | ✓ |
| 同一日内地址互不相同 | ✓ |
| $\mathrm{canon}[v]$ 即 $v$ 出生所在间隙，且 $\mathrm{simplest}(\mathrm{canon}[v])=v$ | ✓ |
| 递归序 $==$ `Fraction` 序（生日 $\le6$ 的 127 个数，**全部 16,129 对**） | 0 mismatch ✓ |
| $\mathrm{day}\le3$ 的**有效形式** 576 个，其值覆盖全部 15 个数 | ✓ |

**576 不是只信程序**：$\sum_{lo<hi}2^{\#\{x<lo\}}\cdot 2^{\#\{x>hi\}}=1+127+127+321=576$，手算一致。

## 5. A：序下降 —— 331,776 对，0 mismatch

| | |
|---|---|
| 比较对数 | $576^2=331{,}776$ |
| mismatch | **0** |
| 判决 | **DESCENDS** |
| 呈现同一个值的形式互为 $\le$ | True——**全部 25,600 个同值有序对**（其中 64 个形式呈现 0） |

> **序是呈现无关的：形式怎么呈现，都不改变"谁在谁之前"。**

这是康威构造里 $\le$ well-defined 的**重算**（不是新定理，见 §9）；
本次的用处是把它**定位**到"序下降"这一侧，与下一节的撕裂配成一对。

---

## 6. B：呈现日撕裂

**见证对**（形式按**呈现日升序**喂入时，判据最先遇到的分歧——第 1 日没有 0 的呈现，
所以第二项最早只能落在第 2 日）：

| | 形式 | 呈现日 | 值 |
|---|---|---|---|
| $h$ | $(\ \mid\ )$ | 0 | 0 |
| $h'$ | $(\ \mid 1)$ | 2 | 0 |

$$q(h)=q(h')=0,\qquad c(h)=0,\ c(h')=2 \quad\Longrightarrow\quad \textbf{TEAR}$$

**同一个值 0，在截断内的呈现分布**：

| 呈现日 | 0 的呈现数（$\mathrm{day}\le3$ 内） | 例 |
|---|---|---|
| 0 | 1 | $(\ \mid\ )$ |
| 2 | 3 | $(\ \mid 1)$ |
| 3 | **60** | $(\ \mid \tfrac12)$ |
| 合计 | 64 | |

**无限族**：$(\ \mid n)=0$ 且 $\mathrm{day}=n+1$（$n=1..10$ 实测 ✓）。
所以 0 在第 $0$ 日与**每一个 $\ge2$ 的日子**都有呈现 → **纤维无限**。

两件事一起说才准确：

- 呈现日**不是**值的函数（TEAR）；
- 而且它在**每一天的切片上是常数**——第 3 日一天之内有 60 个呈现都等于 0，
  该 clock 对它们读数完全相同。**在切片内，它的分辨率为零。**

## 7. C：容量——两种读法，两个结果

| 呈现日 $d$ | 当日出生的数 | $\lceil\log_2\rceil$ | L/R 地址用掉 |
|---|---|---|---|
| 0 | 1 | 0 | 0 |
| 1 | 2 | 1 | 1 |
| 2 | 4 | 2 | 2 |
| 3 | 8 | 3 | 3 |

- **在"日类"里**（状态 = 生日、clock = 地址）：地址**恰好用满** $d$ bit → **饱和**。
- **在"值切片"里**（状态 = 值、clock = 呈现日）：切片内有 60 个呈现、读数全同 → **零分辨率**。

对照 `helgoland/notes/tear-witness.md` §5 的载体：纤维 6 条历史 → 容量 3 bit，
而 Koszul 符号只花 **1 bit**（$1/3$）。

> **所以饱和是可达的——但达到饱和的那个 clock 是"规范地址"，不是"被搬运的数据"。**

## 8. 这张表是什么意思（读法，不是定理）

| frame | 状态 $q$ | clock $c$ | 判决 |
|---|---|---|---|
| AES | 基点 $(u,v)$ | 值 $a$ | **TEAR** $=\mu p(e^{\lambda q}-1)$ |
| Surreal | **值** | **呈现日** | **TEAR**（§6） |
| Surreal | **值** | **序** | **DESCENDS**（§5） |
| 狭义相对论 | **事件** | 某观察者的**时刻** | TEAR（**同形读法，未算**） |
| 狭义相对论 | **事件** | **因果序** | DESCENDS（**同形读法，未算**） |

读法：

- **序是规范无关的**：谁在谁之前，与它怎么被呈现无关。
- **呈现日不是**：同一个内容可以在不同的日子被给出。
- 于是"同一个内容、不同的日子"与"同一个事件、不同观察者给出不同时刻"**同形**；
  而序（因果序）正是下降的那一个。

**标注**：后两行是**同形读法**，本节没有计算它们；本节也不主张任何物理结论。

## 11. 留给你的问题（我建议的优先级）

1. **AES 有没有"最简形式"？**
   surreal 这边撕裂之所以无害，是因为存在**规范截面**（每个数取最简呈现），
   生日因此成为**值**的函数。AES 那边没有这个截面，$\mu\lambda$ 就只能被**携带**。
   **"AES 的 canonicalization 是什么"**——这一问答出来，撕裂语言就闭环了。
2. **饱和问题该改写**：日类里饱和的那个 clock 是**规范地址**，不是**被搬运的数据**。
   所以要问的是"被搬运的数据能否饱和"；surreal 这边**不给**这个问题的答案。
3. **转动环**：把同时性的物理侧做成 frame（$\mathrm{d}\omega$ 与 $\oint\omega$），
   看它落在"**非闭**"（AES 型、局部不可积）还是"**闭而不恰当**"（Sagnac 型、拓扑）
   哪一边——这正好是今天在 `tear-language.md` 修正的那个用词在**物理侧**的落地。
