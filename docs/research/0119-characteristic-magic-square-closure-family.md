# Research 0119: Characteristic magic-square closure family

## Question

Can a bounded arithmetic search discover one closure, survive interruption, and
then use the certified result to generate a nontrivial internal family whose
members, paths, local reuse, and interactions remain separately auditable?

The magic square is a controlled substrate. The research object is the
post-closure growth process.

## Problem and exact anchors

The raw assignment space of a normal order-four magic square is `16!`. A complete
candidate must use every integer from one through sixteen exactly once and close
ten line sums at thirty-four.

Line closure is additive. Domain closure is the exact polynomial equation

\[
P_x(t)=\prod_i(t-x_i)=\prod_{k=1}^{16}(t-k)=P_{16}(t).
\]

The second equation is insensitive to cell order, while the first ten equations
depend on spatial incidence. Their separation is useful: swapping the first
cells of rows zero and one preserves `P_x = P_16` but violates line closure.
Thus arithmetic content alone cannot erase space.

For a partial assignment the implementation retains the unused values and
derives the remaining characteristic-factor digest after every step. At complete
closure the remaining product is one. No failed branch contributes a zero
factor; it is cut by the exact feasibility predicate.

## Bounded discovery

The method is frozen to:

- choose the first row-major open cell;
- try unused values in ascending order;
- cut a completed non-34 line;
- cut a partial line when the smallest or largest available completion cannot
  reach 34;
- retain every valid but unselected closure by content digest;
- select the first closure with a sixteen-member orbit under the three declared
  transport generators; and
- stop on selection or recorded fuel exhaustion.

The input/output boundary remains:

\[
(subject,method,object)\longrightarrow(history,result,evidence).
\]

The run uses `learn` because it proposes and tests fillings of an open subject.
The exact certificate is still independently replayable by verification code.

## Closure-generated structure

Let `r` rotate the grid clockwise, `s` reflect it vertically, and `c` complement
each value by `17-x`. Starting from the selected certificate, bounded unfolding
constructs the orbit graph generated by `r`, `s`, and `c`.

The experiment checks these relations on every generated member:

\[
r^4=1,\quad s^2=1,\quad c^2=1,
\]

\[
cr=rc,\quad cs=sc,\quad srs=r^3.
\]

The equal endpoints do not erase the two words. They form retained coherence
witnesses. Each unique global member has a fresh occurrence; content sharing is
not occurrence identity.

Every global member contains ten line-closure occurrences. Sorting the four
values of a line yields a reusable local content coordinate. Separately, two
line occurrences influence one another when their checked cell sets intersect.
This distinguishes three things that a flat solution list would collapse:

1. global closed objects;
2. reusable local closure contents; and
3. incidence-sensitive interactions between local closures.

The executable run is expected to expose, and CI will freeze, at least:

| observation | expected value |
| --- | ---: |
| expanded search nodes | 12,517 |
| earlier valid closures retained | 2 |
| generated global members | 16 |
| directed generator edges | 48 |
| line-closure occurrences | 160 |
| unique local line contents | 12 |
| line-incidence influences | 32 |
| checked family relations | 6 on every member |

Two complete fill schedules, row-major and column-major, reach the same closure
content and final remaining-factor digest while retaining different assignment
histories. A 5,000-node run remains open; continuing its saved frontier with
10,000 more nodes reaches the same selected closure content as the uninterrupted
15,000-node run.

## Interpretation and boundary

The deeper result, if the run succeeds, is not that a magic square was solved.
It is that one certified closure changed the available internal vocabulary: it
became a seed for new occurrences, maps, equal-endpoint path comparisons, local
content reuse, and an influence graph.

This remains a sharply bounded result. The method already knows the three
symmetry generators and the sixteen-member selection criterion. The experiment
does not learn its own transformations, assign external meaning, prove that
growth remains productive, or show that independently generated closure
families will compose. It provides a finite object on which those stronger
questions can next be asked without relying on metaphor.
