# 0194 — 实测的 key+cert 代价：锚点链**接不起来**，钥匙那一半在本机测不到

Status: bounded measurement over retained tooling, research-only. Evidence:
`experiments/measured_join_cost/evidence.json`（108 断言，12 条链接）。这一轮执行的是 0193 结尾
建议里的**第 1 步**：把"连接代价"从**声明**换成**实测**。

## 1. 怎么测的

在**临时副本**上跑保留的三条命令（**保留的锚点与记录一个字节都没写**，副本用后即删）：

```
lineage-update --root <scratch> --package arithmetic --global-seq k --anchor-out <scratch>/anchor-k.json
tamper-check   --root <scratch> --anchor <anchor-k> [--prev-anchor <anchor-(k-1)>]
key-issue      --purpose anchor-signing --home arithmetic --policy-version 0 --output ...
```

共 12 级（`k = 1..12`），每级记录工具**自己报告**的 `units` / `bytes_read` / `wall_ms`
与实测墙钟、锚点字节数、`self_sha256`、以及 `tamper-check` 的**判定**。

## 2. 证书那一半：**可测、可复现、而且在同一个锚点内确实成立**

- **同一锚点内**：`tamper-check` 报告 `status: Intact`、`anchor.match: true`（检查点对锚点），
  用 **2 units**、读 **2031 字节**——这是保留的 Merkle 与哈希链机制**真的在工作**。
- **建一个锚点**：**1 unit、读 749 字节**，并且**每级都恰好是这两个数** ✓（常数）。
- **锚点字节数**：`k = 1..9` 是 **533**，`k = 10..12` 是 **534** ✓✓
  —— 因为它带着自己的序号，所以**增长是位数式的（对数）**。

**这一条直接修正了前两轮的声明**：0192/0193 声明的"常数 / 线性 / 翻倍"三种形状**全都不是实测形状**；
实测是**对数式**。**这就是"该测而不是该声明"的用处。**

## 3. 锚点之间的链接：**接不起来**（工具自己的判定）

- **每一个**建出来的锚点、以及 `0158` 证据里的**每一个**保留锚点，
  `prev_anchor_sha256` 都是**空串** ✗；
- 于是带前任锚点的检查给出 **`status: Tampered`、`reason: "prev_anchor mismatch"`** ✗✓
  —— 这正是你协议里的**"接不起来"那一支**，而且是**测出来的**，不是我推的。
- 附带一条**代价学**的细节：链接失败时工具**在做工作之前就中止**（`units: 0`、`bytes_read: 0`），
  所以**失败的连接比成功的连接更便宜** ✓ → **准备金必须按"成功那一支"定价**，不能按失败定价。

**我自己的一个假设在这里被反驳**：第一次看到空字段时我判断是**我复制输入复制错了**（只拷了
`lineage/`、没拷上一级的 `anchor.json`）。改成整根复制之后，字段**仍然是空的** ✗ ——
**假设错了，事实是工具不写这个字段**。两次都留在这里。

## 4. 钥匙那一半：**本机测不到**

```
key-issue -> status: Unknown, exit 3,
             reason: "ed25519 backend missing; no key generation without it"
             record_written: false, private_seed_written: false
```

所以：**签名既没生成也没验证**（所有锚点 `signatures: []`）→ 本轮测到的代价是
**下界**；**钥匙那一半以一个显式未知量进入**，没有被悄悄当成零。

## 5. 对准备金的意义（把实测代进 0193 的表）

用**实测的证书代价**（1 unit、749 字节、对数增长）加**声明的换算**（一条链接折算成几个层步）重算：

| 换算（层步/链接） | 1 | 2 | 4 | 8 | 16 | 32 | 64 | 128 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 最优准备金（步 / 1000） | 127 | 126 | 124 | **248** | 240 | 224 | 192 | 128 |
| 折合 | 12.7% | 12.6% | 12.4% | 24.8% | 24.0% | 22.4% | 19.2% | 12.8% |

- **1% 在所有这些换算下都不是最优**——**哪怕一条链接只值一个层步**（那时最好仍是 **127 步**）；
- 最优值是**跳变**的（层级按整单位买、深度天花板是开方），所以"最优准备金"是换算的**阶梯函数**，
  不是一个数；
- 换句话说：**准备金的合理量级是 12%–25%，而不是 1%**，除非层级真的近乎免费。

## 6. 本轮记录在案的错误（四处）

1. **"验证代价是常数"**——预期错：链接失败时该工具**提前中止**（`units: 0`），所以那一列只在
   **真正接上**的级别上有意义。
2. **"锚点字节是常数"**——预期错：它随**序号位数**增长（533 → 534）。**实测形状是对数式。**
3. **空字段是我复制错误**——假设错：整根复制后字段**仍然为空**（工具不写它）。
4. **在一个以"实测"为目的的运行里用了浮点**：深度天花板原本写成 `pool ** 0.5`（binary64）✗，
   已换成**整数平方根**。**浮点开口清单会抓到它**，但它是本轮**最不该**有的东西。

## 7. 本轮**没有**主张的

- **没有**测量 Ed25519：没有生成、没有验签，钥匙那一半**是未知量**。
- **没有**主张"锚点链在原则上不可能建立"：本轮只报告**这条工具路径**给出的判定
  （空字段 + `Tampered`），它可能的正确用法（例如由运维按 0156 的公式写入前任哈希）**不在**本轮范围。
- **没有**把实测工作换算成层步的**唯一**答案：换算仍是**声明参数**，本轮给的是**函数**（表）。
- 覆盖范围是一根根、一个包、12 级；**"代价随层级对数增长"是在这里的测量，不是普遍定理。**
- 保留的锚点、凭据、密钥、血统记录**一律没动**；三侧读法的**张力**照旧未化解。
