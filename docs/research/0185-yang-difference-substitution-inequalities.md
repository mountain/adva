## 3. 被检验的证书

变量非负时，把**第 j 小的变量**换成**前 j+1 个差分变量之和**（最小者换成第一个差分变量，次小者换成前两个之和，依此类推）。在有序列锥 `0 ≤ x₁ ≤ x₂ ≤ … ≤ xₙ` 上，这个代换恰好就是换到非负的差分变量，所以**代换后系数全非负 ⟹ 该锥上非负**。又因为任意非负点都能被某个次序排成有序，**对全部 n! 个次序都通过 ⟹ 整个非负象限上非负**。

这个论证在代码里被当作恒等式检查：对每条命题、每个次序，在随机精确有理点上核对"代换后多项式在差分处取值 = 原多项式在该点取值"（12 次/条，全部相等）。

证书**可靠但不完备**：没有次序通过就是 `Unknown`，绝不是反例；假命题另行用**一个显式精确有理点**否证，且明确记为控制项而非证书结局。这正是与 2.2 里"可证可否证"的差别所在。

## 5. 这一轮真正学到的

**（1）证书够到了平方和锥之外。** Motzkin 多项式是"非负但不是多项式平方和"的经典例子，本次**6/6 个次序全部通过**（差分像 18 项、系数全非负）。也就是说：差分代换证书与 SOS 证书是**两个不同的锥**，前者在这里更强。（"Motzkin 不是平方和"是经典事实，本轮**只引用、未验证**。）

**（2）我们自己的不等式恰好落在两者之间。** 0171 那条"边缘是判别式的零点、不稳定带因此有界"的不等式，在本次 24 个次序里**一个都没通过**；但它的平方和恒等式 `c_s²k² − (2c_sκ − s)k + κ² = (c_s k − κ)² + s k`（其中 `g = 2c_sκ − s`）被**精确验证**（不是抽样）。所以：**这条不等式有 SOS 证书，没有差分代换证书**——两种证书是不同的对象，笔记里分开记。

**（3）Schur 有一条"有序证书"，可读性完全不同。** 恒等式 `Σ_cyc x(x−y)(x−z) = (x−y)²(x+y−z) + z(x−z)(y−z)` 被精确验证；在锥 `x ≥ y ≥ z ≥ 0` 上五个因子全部非负，于是它是一份**人能读、能逐步核对**的证书（与 0184 消点法的可读证明同类）。它与差分代换证书并存，说明"机器证书"与"可读证书"不必是同一个东西。

**（4）朴素迭代不会加强证书。** 把代换再做一次，只证明了"差分变量本身也有序"的那个子锥，而这是严格更小的锥：显式反例是 `x = (0,2,3)`——它本身在有序锥里，但差分为 `(0,2,1)`，不有序。所以"逐次"这一步**不是**简单地把同一个代换重复施加。

## 8. 本轮自己犯的错（保留在记录里）

1. **Schur 的不等式被我写错了。** 我最初写的形式是 `x³+y³+z³+xyz ≥ xy(x+y)+yz(y+z)+zx(z+x)`，**它在 (1,1,1) 处取值 −2，是假命题**；于是"Schur 未被认证"这个结果其实是我写错命题造成的，不是方法的性质。发现方式是在准备有序证书时手工代入对称点，**不是**运行里的抽样审计——抽样审计通过了，因为随机有理点几乎不可能三坐标相等。
   修正为 `Σ_cyc x(x−y)(x−z) ≥ 0` 后，Schur **6/6 全通过**。
   作为回应，本次运行**对每一条声明为真的命题都做见证搜索**，并加了一条检查"声明为真的命题必须搜不到负值见证"——这才是本该抓到它的检查。
2. **有序证书的恒等式第一次配错了多项式。** 我推导出的形式里多了一项 `2xyz`，那是**配着上面那个错命题**推出来的。这一次是**运行里的精确恒等式检查直接拒绝**（"the ordered certificate must be the same polynomial"），改正后为 `(x−y)²(x+y−z) + z(x−z)(y−z)`。
3. **契约里的两条验收判据曾按错误的测量结果写下**（"Schur 不被认证"），在命题修正后一并改正；契约与判据的这次改动发生在提交之前，并且原因记在本节。
