# 0190 — 多变量这一级：历史方法的逆步在这里没有对象，而"单射"不等于"幸运"

Status: bounded exact experiment, research-only. Evidence:
`experiments/aeg_core_shell_multivariate/evidence.json` (contract and checker beside
it, 5409 assertions, contract digest pinned in the evidence). The shell form and the
"shell participates in canonicalisation" decision come from
[note 0189](0189-core-shell-and-symbolically-unexpanded-shell.md); the notation this
implements is registered in
[`docs/terminology/aeg-core-shell-notation-v0.json`](../terminology/aeg-core-shell-notation-v0.json).

## 0. 这一级要问什么

上一级在**一元**有理函数片断上做了核 + 符号未展开壳。这一级把变量数加到两个，问三件事：

1. 秦九韶大衍求一术（以及它在 `Z` 与 `Q[x]` 上靠的**扩展欧几里得**）在**多变量**上还有没有
   它要作用的对象；
2. 把多变量问题**降到一元引擎**的克拉默（Kronecker）代入，什么时候是**精确的相等判定**，
   什么时候能当**除子路线**；
3. 上一级**尚未测量**的那件事——截断载体与精确载体的**复合测量**——在这里补上。

冻结的族是 `g = x + y`、`h = x² − 1`、`k = y² + 2`，真除子 `g` 按构造成立；左/右两对是
`g·h` 与 `g·k`（以及 `g·h·h` 与 `g·k`）。一切精确：有理函数是多项式对，相等性靠**交叉相乘
是否为零多项式**判定，没有浮点，没有 GCD 需求。

## 1. 逆步没有对象——这一条是**证明**，不是搜索结果

`Q[x₁,…,xₙ]`（n ≥ 2）是唯一分解整环，但**不是**欧几里得整环，**不是**主理想整环，也
**不是** Bézout 整环。检查器给出的是证明而不是穷举：

> 在原点取值：`p·x` 与 `q·y` 的每一项都含正次数，故左边为 0，而右边为 1。

因此**不存在**满足 `p·x + q·y = 1` 的多项式 `p`、`q`，扩展欧几里得的求逆步在多变量上
**没有目标对象**。同样这句话的反面也要说清楚：本次还做了有限搜索（`p`、`q` 各取声明界内的
**单项式且系数为一**，196 对），**一个见证都没找到**——但这只是**在声明族上的有界否定**，
状态写作 `bounded negative over a declared family, not the proof`，不是证明。真正的证明是上面
那次取值。搜索的作用只是与证明保持一致，而不是取代它。

值相等这一侧则完全不需要这些机制：两条路（交叉相乘、声明点抽样）都**不使用 GCD**、
**不使用单项式序**——检查器把这两个字段作为**断言**记下来，测试也会检查它们保持为 `false`。

## 2. 克拉默代入：阈值是**导出来**的，不是声明出来的

代入 `x_i ↦ t^{base^{n−1−i}}` 是环同态；它在**每个变量的次数都小于 base** 时是**单射**，
此时**相等判定是可靠的**。这个阈值由实际次数导出：本族的单变量次数上界是 3，因此阈值是 4。

本轮的第一处自我纠正就发生在这里：我先把 base 3 写成"幸运"、把 base 1 写成"退化"。
**base 3 并不满足单射条件**（`y³` 与 `x` 的像都是 `t³`），而 base 4 才是满足它的那个。
契约现在不再预先命名幸运值，而是**声明一组待测指数、由运行把每一个放到阈值的哪一侧**。
记录在案的碰撞见证是：

| base | 单射 | 碰撞见证 | 除子像相符 |
| --- | --- | --- | --- |
| 4 | 是 | — | 是（测量） |
| 3 | 否 | `y³` 与 `x`，同为 `t³` | 是（测量） |
| 1 | 否 | `y` 与 `x`，同为 `t` | 是（测量） |

即：**非单射的代入可以让两个不同的多项式看起来相等**，所以相等判定只在单射时可靠；
而"代入后求出的 gcd 恰好等于真除子的像"在这三处都成立，**但这是对这一对的测量**，
不是保证。降到一元引擎并没有解决除子问题。

第二处自我纠正也在这里，而且方向相反：初版把退化 base 下的"多余因子 `1/2`"当成失败，
其实那是我拿**未首一化**的真像去比较——差的只是一个标量，首一化之后两边相同。修正后三个
指数上都是"相符"。**那一格记录的不是失败，是我的比较方式错了。**

## 3. 同余路线：**逐格测量**，而且单射≠幸运

模 `p` 的像与声明点特化是这类方法的同余一半。本轮不把"像等于除子"写成断言，而是**逐格
记录**（指数 4/3/1 × 素数 5/7/11，加 3 个特化点），并且要求**每一个不利格都交出多余因子**：

- **11 格恢复，1 格不利**；
- 不利格是模 **5**、指数 **4**——注意**它是那个满足单射条件的指数**：像为
  `x⁶ + 2x⁴ + x³ + 2x`，除子像是 `x⁴ + x`，多余的因子是 **`x² + 2`**；
- 这个因子能被解释而不是被描述：`x² ≡ −2 (mod 5)` 给出 `x⁸ ≡ 1`，所以 `t² + 2 | t⁸ − 1` 在
  `F₅` 上成立，而 `t² + 2` 正是 `k` 的像。也就是**两个非除子因子在模 5 之下共有了一个因子**。

结论：**代入的单射性与"像是否幸运"是两个不同的条件**。前者可以导出并检验，后者是逐格
测量出来的，而且**在单射的那一格上就失败了**。这一半没有任何有理重构被实现。

## 4. 上一级留下的那次复合测量，这一轮补上了

上一级只做到"截断后的壳不再等于精确残差"，没有把**截断载体与精确载体**放在一起测。本轮在
声明的分母 `h + 2 = x² + 1` 上（常数项非零，逆才存在；`1 + h = x²` 会被检查器以
`InverseNeedsANonzeroConstantTerm` 拒绝）对 1、2、3 阶做了这次测量：

- 截断逆在**每个声明阶上都存在且精确**，其损失**恰好落在正次数项构成的理想里**，且**非零**
  ——所以它是**可见的**；
- 与精确载体相比，**内容层不相等**（`content_equal = false`），**对象层也不相等**
  （`object_equal = false`，差在**来源**：截断载体带截断出处，精确载体带未展开余项）；
- 但**不相等是可检测的**（`content_inequality_is_detectable = true`），因为余项非零；
- 代价也记下来：一阶时精确对 3 个单项式，截断载体 2 个。

也就是：截断省下了代价，它丢掉的东西**带标签、可见、不会被误当成精确载体**——但**不会被
恢复**。这与上一级的结论一致：被满足的是**增长的精确控制**，**不是可识别性**。

## 5. 本轮记录在案的错误

1. **乐观命名**：先把 base 3 叫"幸运"。实际次数上界是 3，阈值是 4，base 3 不满足单射条件。
   契约已改为"声明待测指数、由运行放置"。
2. **比较方式错误导致的假失败**：退化 base 下的"多余因子 `1/2`"是未首一化比较的产物，修正后
   该格为"相符"。真失败在别处（§3 的模 5 那一格）。
3. **显示形式的系数/指数错位**：测试里从 `1x`（无指数）读回了常数。这是本仓第三次同类错位，
   所以测试改为**按变量定位**而不是按顺序消费。

## 6. 本轮**没有**主张的

- **不主张**多变量规范化（首一代表、单项式序、Gröbner 基）已经实现：本轮只用**等价关系**
  （交叉相乘），**没有**选出代表元。是否需要代表元仍未决。
- **不主张**任何有理重构、公式重构或 CRT 组装。
- **不主张**"求一"与投影见证之间的对位是**同构**：它是**解释**（见
  `adva-library/meaning-qin-jiushao-dayan-duality-v0.md` 的边界声明），本轮的负面结果也不改变
  这条边界。
- **不主张**搜索的耗尽等于不存在：搜索只报告**有界否定**，证明来自取值。
- `native_status: NotRun`。这一级是研究记录，不进入稳定 API，不授权任何稳定操作。
