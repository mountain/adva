# 0202 — 一步关掉的孔比打开的多吗？——**按货币分别可判**

Status: bounded exact counting, research-only. Evidence:
`experiments/aperture_ledger/evidence.json`。这一轮回答的是一个**方法问题**，
用的全是**已保留的账**，不重跑任何实验。

## 1. 先说结论

**能判定，但必须先声明"用哪种货币数"。**记录里已经有**三种**互不相同的孔：

| 货币 | "孔"是什么 | 这一步的净额 |
| --- | --- | --- |
| **扫描器** | 某实验是否含**决定判定**的浮点/主机构造 | **净关闭 +7** ✓ |
| **质量** | 未被解出／未定的质量 | 解出步 = **−1**（纯关闭）；**截断步 = 0** ✗ |
| **陈述** | 记录里**带着的错句** | **0**，且带**结构性下限** ✗ |

**三种不能相加** ✗ —— "关的比开的多吗？"这个问句**缺少一个货币参数**时是无解的 ✓。

## 2. 扫描器货币：整线**净关闭 7**，而且**只有一步**开多于关

13 个复扫点，四个计数器（`exact-only` / `can-decide` / `illustration-only` / `no-numeric`）：
`exact-only` 从 **5 涨到 13**（关 8），`can-decide` 从 **37 涨到 38**（开 1）→ **净关闭 +7** ✓。

**唯一"开多于关"的一步是 `after 0192`** ✓ —— 而那一步**正是**把两个浮点探针**有意**放到
验收路径上的那一轮（它要测的就是 binary64 在"0.33×3+0.01"上做什么 ✓）。**开口是那一轮的题目**，
不是它的疏漏 ✓。

**两个净额**（严格／宽松）：`illustration-only` **也是开口**（只是不决定判定），
所以"严格净额"（只数决定判定的）与"宽松净额"（把 illustration 也算开）**在四步上不一致**：
`after 0191 / 0193 / 0194 / 0195` ✓ —— **"一个开口算多少"本身也是要声明的** ✗。

## 3. 质量货币：**解出净 −1，截断净 0**

- **解出一步**：关掉一层，**不开任何东西**（自身空间单调闭合 ✓）→ **净 −1** ✓；
- **截断一步**：关掉一层，但**打开一个落在截断理想内的残差**，其质量与关掉的那层**同阶** ✓
  → **净 0** ✗ —— **截断买一层、也付一层**（0191 实测过那个残差非零且可检测 ✓✓）；
- 另有一处：**第 2、3 层什么都不改变** ✓（没有长度为 2、3 的已接受柱 → 未定质量原地不动 ✓）
  —— 这正是 0201 从**接受侧**看到的死区，在这里从**闭合侧**再次出现 ✓✓。

## 4. 陈述货币：**净 0，且有结构性下限**

- **关闭**：追加**更正节** → 目前 **2** 处（0194、0198 ✓）；
- **开着的**：被后来**重算反驳**、但按"冻结不改写"**必须留在冻结证据里**的句子 → **2** 处 ✓；
- 于是 **净 0** ✗ —— 而且这不是"还没做完"：**冻结的意义**就是**不许回头改** ✓，
  所以**这个货币永远不可能被"改正笔记"压到零以下** ✓✓ —— 它是**结构性下限**，不是失败。

## 5. 于是"方向"这条规则怎么用

方向想要的规则是"**沿净关闭的方向走，一步接一步关掉越来越多的孔**"。本轮把它变成可执行的三句：

1. **先声明货币**（以及"一个开口算多少"✓，见 §2 的两个净额）；
2. **在该货币下要求净额为负**（即关闭多于打开 ✓）；
3. **把结构性下限单独列出**，**不计为失败** ✓ —— 质量货币的截断步（净 0 ✓）与陈述货币
   （下限 0 ✓）都属于这一类：它们不是"这一步白走"，而是"**这一步的账必须这么记**" ✓。

**这一线自己的读数**：扫描器货币 **净关闭 +7、只有 1 步开多于关** ✓ → **方向是通的**；
而在另外两种货币上，**净额停在 0 是结构决定的**，不是可以靠更努力走掉的 ✗✓。
