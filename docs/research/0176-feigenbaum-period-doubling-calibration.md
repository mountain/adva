## 0. 这份记录做什么

先查到了两个常数的已发布值（OEIS A006890 / A006891，b-file 各 1019 / 1018 位），然后**不是引用它们，而是从定义重算**，并数清楚重算结果与已发布值**有几位一致**。这一步是本记录的全部内容：把"网上写着 4.669…"变成"我们自己算出来的前 12 位与它逐字符一致"。

## 2. 方法与事前声明

对有一个临界点 `c` 的单参数区间映射族，`r` 在**第 k 级超稳定** ⟺ 临界点落在周期 `2^k` 的环上，即 `h_k(r) = f_r^{2^k}(c) − c = 0`。取 `r_{k−1}` 之上的**首个**根为 `r_k`，则

```
δ_k = (r_{k−1} − r_{k−2}) / (r_k − r_{k−1})
α_k = −(x_{k−1} − c) / (x_k − c),   x_k = f_{r_k}^{2^{k−1}}(c)
```

**事前声明**（写进契约，先于运行）：

- 全部报值用 **90 位 `Decimal`**；二进制浮点**只**用于定位括号，不用于任何报出的数字。
- Aitken Δ² 外推**只是加速器**，不是定义的一部分；一致位数之外的数字**不主张**。
- 已发布的位数是**比对目标**，不是推导来源。
- 成功条件：δ 与 α 各至少 **12 个前导字符**一致；普适性控制至少 **8 个字符**；异类控制必须**不同**（差 > 0.1）。

## 3. 结果

主映射：logistic `f_r(x) = r x (1 − x)`，临界点 `1/2`，跑满 **k = 1…16**。

| 量 | 结果 |
|---|---|
| `δ_16`（未外推） | `4.6692016090577589360884198` |
| **δ（Aitken）** | **`4.6692016091027313185348330`** → 与已发布值 **14 个字符一致**（即 12 位小数） |
| `α_16`（未外推） | `2.5029078751443513664271859` |
| **α（Aitken）** | **`2.5029078750959265421192102`** → 同样 **14 个字符一致** |
| 累积点 | `r_16 = 3.5699456718404126096918345`，与常用的 `r_∞ ≈ 3.569945672` 相符 |

**精确控制**：第 1 级超稳定参数有闭式 `r_1 = 1 + √5`。检查器既做数值比对（差值 < 1e-30），又在 `Q(√5)` 上做**整数对运算**验证多项式恒等式 `r³ − 4r² + 8 = 0`（结果恰为 `(0, 0)`，精确成立）。

**普适性控制**（同类不同映射）：sine 映射 `f_r(x) = r sin(πx)`，同样方法得 `δ = 4.6692016113522…`，与 logistic 的结果 **9 个字符一致**——这是普适性在这个模型里被检查到，而不是被引用。

**异类控制**（不同普适类）：四次映射 `f_a(x) = a − x⁴`，得 `δ = 7.2844857008722864571895235`，与 logistic 的 δ 相差约 2.6 ✓。**本记录不主张与文献中该类的值相符**——这一比较没有做。

## 4. 这个检查确立什么、不确立什么

**确立**：在这个仓库里，用定义级的迭代与声明的精度，可以复现 δ 与 α 的**前 12 位小数**，并逐字符数清一致位数；普适性在 logistic 与 sine 之间被检查过；第 1 级的闭式被精确验证。

**不确立**：

- 一致位数**之后**的数字不主张；本方法不是独立证明，而是**对来源的标定**——真要逐位严格，需要在一个函数空间里解 Feigenbaum–Cvitanović 不动点并给出**可验证的误差界**，本记录没有做。
- 不主张两个常数的**代数/无理性质**（来源明说未知）。
- 不涉及其它普适类（面积保持映射、圆映射等），其指数本记录一个都没给。
- 四次映射那一支只证明了"与 logistic 不同"，没有与文献比对。
- 无任何度量、Arakelov、Monge–Ampère、镜像或 Calabi–Yau 内容；无原生 witness、无准入、无 Seal。

## 5. 两个过程错误，留在记录里

1. **更早那次朴素尝试跑偏了**：我把扫描步长取成 `1e-3`，而各级超稳定参数之间的间隙到 k=6 只有 `1.2e-4` 量级，于是**步长跨过了真正的根**，落到了累积点之后的周期窗口里的另一个超稳定解上（当时给出 `r_7 = 3.5704…`，而真值约 `3.5699134…`）。诊断方式是直接采样 `h_7` 在 `r_6` 附近的值，看到变号就发生在 `3.56991` 一带。**"括号内必须发生变号"这条断言就是为此加的**，它让跳根变成可见的失败而不是静默的错误结果。
2. **类型混用**：sine 映射最初写成 `Decimal.sin()`，而 `decimal` 模块**没有三角函数**；同时浮点分支又会拿 `float` 去调用它。修法是两条路径分开，并自己用级数实现工作精度下的正弦（含 `2π` 归约）。
