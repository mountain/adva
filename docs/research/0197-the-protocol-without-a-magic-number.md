# 0197 — 去掉最后一个魔数：准备金由规则导出，且两条独立方法必须给出同一个值

Status: bounded exact check, research-only. Evidence:
`experiments/protocol_declaration/evidence-v1.json`（继任声明与 v0 的冻结记录并列）。
本轮是 0196 结尾建议的第 1 步。

## 1. 继任声明改了什么

`protocol-v1.json`：**准备金不再是一个固定分数，而是由规则导出**。

| 项 | v0（冻结） | v1（继任） |
| --- | --- | --- |
| 准备金 | 声明值 **1/100**（现行） | **规则导出**（`operative_value: derived`） |
| 导出规则 | — | **交叉规则**：使"买到的层级"**首次追平**"剩余步池所能到的深度"的最小整步准备金 |
| 方向的 1/100 | 现行值 | **历史值**（保留用于比较，不再现行） |
| 判据措辞 | "…是定价准备金，**或声明必须写明差距**" | "…**等于独立穷举扫描找到的最优值**" |

注意最后一行：**继任把这一条判据改强了**（去掉了"写明差距即可"这条退路），**不是放松**；
其余五条判据**逐字未动**。

## 2. 判定：**v1 六条全过；v0 仍然恰好一条不过**

```
[pass] 分配在整步上精确闭合
[pass] 声明的侧边分法是该步池下的拉平分法
[pass] 声明的准备金等于独立穷举扫描找到的最优值     ← v0 在这里不过
[pass] 钥匙一半已测、或带着附加量/界
[pass] 回推触发条件点的是保留判定字段
[pass] 接上一条链接抬高天花板一层、解出一层使剩余质量减半
```

**同一份检查代码，两份声明，判定不同** ✓ —— 这才说明检查**有判别力**，而不是"给什么都通过"。

## 3. 非平凡性：**派生声明最容易变成同义反复**

第一版 v1 的写法是"派生值 = 扫描值"，那么"声明值 == 扫描值"就是**恒真** ✗ ——
**检查等于没查**。修法是要求**两条独立方法**：

| 方法 | 是什么 | 结果 |
| --- | --- | --- |
| **A：声明的规则** | **交叉规则**（买到的层级首次追平步池深度） | **225 步** |
| **B：独立穷举** | 扫描**每一个**整步准备金，取已解出质量最大者 | **225 步** |

两者一致 ✓（若不一致，本轮会**响亮地失败**而不是悄悄通过）。

## 4. 历史值保留可读（不是删掉）

- 方向的 **1/100** 在预算 1000 下是 **10 步**，买到 **1 层**；
- 导出的 **225 步**（= **9/40 = 22.5%**）买到 **26 层**；
- **残余质量差距 = 33554431/134217728 ≈ 0.25** —— 0196 的那条不及格记录**仍然可读** ✓。

## 5. 冻结记录：按摘要钉住，并逐字节复现

v0 的声明与证据**摘要被钉住**（`checker-v1.py` 里两个常量）；运行时会：
① 核对两个摘要 ✓；② **重跑 v0 检查器**并确认结果与冻结证据**逐字节相同** ✓；
③ 确认 v0 **仍然恰好一条不过** ✓。**保留记录不改写**。

## 6. 本轮记录在案的错误（两处）

1. **同义反复的危险**（§3）：派生声明若是"取扫描值"，判据恒真 ✗ ——
   已改成**两条独立方法**（交叉规则 vs 穷举），并把它写进声明文件本身。
2. **类型疏漏**：v1 里有一条判据函数沿用了 v0 的"返回 (判据, 布尔)"形状，而其余返回字典 ✗ ——
   被运行时的 `TypeError` 拦下，**在写入记录之前**。

## 7. 本轮**没有**主张的

- 判定讲的是**声明的模型**：连接价格仍经**声明的换算**进入，**不是测量**；
- **钥匙一半仍未测**（`ed25519 backend missing`）→ 协议仍是**纯证书定价**；
- **没有**论证最优性：本轮只是把"最优"这个要求**交给扫描**，并把"声明必须与扫描一致"变成判据；
- **没有**读取或改写任何保留的锚点/凭据/密钥；**没有**原生改动；
- **三侧张力**照旧未化解（0192 §8）。
