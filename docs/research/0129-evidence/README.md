## 本批边界与残余

- 全部为**采样搜索**，任何长度都不声称最优；`exhaustive` 是独立命令（仅 N ≤ 25）且本批未跑；
- energy 随 length 增长（约 N² 量级），跨长度不可直接比较；本批只把 merit 作为归一化读数；
- 本批**不与任何已发表最优 merit 表比较**——那需要单独声明来源与适用范围，本次未做该导入；
- 每轮族各不相同（相邻 length），是本批「预期有新证据」的理由；但新证据只是**新族的采样见证**，不是知识、语言形成步骤或原生词；
- 驱动 `continuation-driver.py` 原样保留；其 `write_exclusive` 拒绝覆盖任何既有工件，Run 1–24 的证据字节未被改动。

`invalid option -- (` 报错退出**，因此当时那句「目标区间干净」的结论
