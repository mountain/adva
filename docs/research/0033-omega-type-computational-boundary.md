# Omega-Type Computational Boundaries

Status: exploratory working research note and executable-research route. This
document records one conjectural synthesis, the exact statements already
available, the main no-go boundaries, and a short sequence of finite
experiments. It is not a governance document, a stable API proposal, a claim
in `claims.toml`, or a change to the active `ProgramSlice` priority.

## Executive thesis

The current cut work exposes a missing completion point. A finite decorated
cut retains two sides, ordered holes, source and occurrence identities, and a
surgery history, while surreal objectification can collapse distinct forms to
one number. The E0 work supplies an exact upper-half-plane arithmetic grid and
an edge-level bridge to cellular cut surgery, but not yet a canonical
multi-hole or completed carrier.

This note studies the following hypothesis:

> The missing point is not primarily another finite value. It is an
> **Omega-type computational boundary**: the directed supremum of all
> finitely certified terminating program mass, nameable from outside the
> process but not computably completed or certified from inside it.

Once programs are encoded by a prefix-free code, probability is not an
independent decoration. The prefix cylinders carry canonical Kraft weights.
Objectification then pushes those weights from intensional program histories
to extensional values, while the uncomputable total terminating mass supplies
a precise one-sided boundary.

The strongest geometric version remains open. In particular, this note does
not identify a numerical Chaitin constant with a canonical point of an
elliptic curve. The working invariant is the **type of boundary**--left-c.e.,
noncomputable, random for a universal prefix-free machine, and obtainable only
as a directed completion--rather than the machine-dependent real number
`Omega_U` itself.

## 1. Exact computability core

### 1.1 Prefix cylinders and halting mass

Fix a prefix-free partial machine

\[
U:\{0,1\}^*\rightharpoonup X.
\]

Each binary word `p` determines a cylinder `[p]` in Cantor space with fair-coin
measure

\[
\mu([p])=2^{-|p|}.
\]

If `dom(U)` is prefix-free, these cylinders are disjoint. Hence

\[
\Omega_U
=
\mu\!\left(\bigcup_{U(p)\downarrow}[p]\right)
=
\sum_{U(p)\downarrow}2^{-|p|}
\leq 1.
\]

For a universal prefix-free machine, `Omega_U` is left computably enumerable,
noncomputable, and Martin-Löf random. Its numerical value depends on `U` and
on the prefix grammar. Therefore the code or machine is analogous to a chart:
it must remain explicit, and no machine-specific value may silently become a
coordinate-free geometric invariant.

### 1.2 The effective-cut obstruction

Let

\[
L_{\Omega}=\{r\in\mathbb Q:r<\Omega_U\},
\qquad
R_{\Omega}=\{r\in\mathbb Q:r>\Omega_U\}.
\]

For universal prefix-free `U`, `L_Omega` is computably enumerable: dovetail
all programs and add the dyadic weight of every newly observed halt. The set
`R_Omega` is not computably enumerable. If both sides were enumerable, they
would give arbitrarily tight effective rational brackets and make `Omega_U`
computable.

This yields the first precise connection with the cut problem:

\[
\boxed{
\text{the left side can be generated by finite positive evidence, while the
right side requires nonhalting information.}
}
\]

The extensional order `L_Omega < R_Omega` exists in ordinary mathematics, but
one finite machine cannot symmetrically construct and certify both sides. A
computational `L | R` must therefore expose an unresolved boundary or use an
oracle; it cannot be treated as an ordinary completed finite cut.

### 1.3 Two finite filtrations

Program length and execution time must not be conflated. Define the exact
finite approximation

\[
\Omega_{n,t}
=
\sum_{\substack{|p|\leq n\\U(p)\text{ halts within }t\text{ steps}}}
2^{-|p|}.
\]

Every `Omega_(n,t)` is a computable dyadic rational and is monotone in both
indices. Moreover,

\[
\Omega_U=\sup_{n,t}\Omega_{n,t}.
\]

The two indices have different meanings:

- `n` is prefix depth, description length, or a candidate computational
  reading of birthday and covering layer;
- `t` is causal depth or runtime;
- the pair `(n,t)` is a **bifiltration**, not yet a double period;
- universality removes any computable modulus telling the machine when the
  two-dimensional approximation is sufficiently close to `Omega_U`.

This is the first finite object that should be implemented. It makes the
proposed singular point the inaccessible corner of a completely exact grid,
rather than a metaphor attached to an infinite computation.

## 2. Objectification as a probabilistic pushforward

Let `Form` be a prefix-encoded space of decorated program or cut forms, and let

\[
\operatorname{Obj}_Q:\mathsf{Form}\rightharpoonup X_Q
\]

be an observer-relative objectification. Define

\[
m_{U,Q}(x)
=
\sum_{\substack{U(p)\downarrow\\
\operatorname{Obj}_Q(U(p))=x}}
2^{-|p|}.
\]

This is a lower-semicomputable semimeasure on objectified outputs. It turns the
noninjective fibre already exhibited by
`0021-surreal-cut-objectification-no-go.md` into a quantitative object:

\[
\operatorname{Obj}_Q^{-1}(x)
\quad\longmapsto\quad
m_{U,Q}(x).
\]

Distinct forms such as `(0 | 2)` and `(0 | 3)` may objectify to the same
surreal number while contributing separate prefix mass. Objectification still
forgets their individual source, occurrence, hole order, and surgery trace,
but its fibre mass records how much encoded intensional history was collapsed.

This does not repair the retraction obstruction. A scalar mass cannot recover
the members of a fibre. The exact carrier must still retain the decorated
form and the residual required by the failed objectification square. The
measure is an additional observer-relative shadow, not a replacement for
source identity.

If `m_(U,Q)(x)>0`, one may write the formal conditional weight

\[
\Pr(p\mid x)
=
\frac{2^{-|p|}}{m_{U,Q}(x)}
\]

for programs in the fibre. In the universal case the normalization is not in
general computable. This is a feature of the boundary, not a numerical
implementation defect.

## 3. What the singularity claim can mean

Three claims must remain separate.

### 3.1 Rejected as a default: coordinate identity

One can set a chosen analytic coordinate equal to a chosen `Omega_U`, but this
is machine-dependent and supplies no modular, geometric, or functorial law.
The equation alone has little explanatory content.

### 3.2 Working hypothesis: Omega-type boundary

Finite certified halting cylinders are compact pieces. Ordered by inclusion
or by accumulated mass, they form a directed computable system. Its ideal or
measure completion adds a supremum not compactly witnessed by any finite
stage. The proposed singularity is this completion boundary.

In this reading, "unreachable" means:

- a finite process may name `Omega_U` symbolically;
- it may enumerate increasing rational approximations;
- it cannot compute the real with a certified error modulus;
- it cannot certify that the complete halting mass has been reached.

The mathematical carrier may be formulated first through domain completion,
valuation theory on the prefix tree, or measure completion. Calling the point
an algebraic node or cusp requires an additional geometric construction.

### 3.3 Open geometric strengthening

A candidate genus-one picture begins with a punctured torus or another
finite-area quotient \(\Gamma\backslash\mathbb H\), then compactifies a cusp
or studies a nodal degeneration. Topologically, a punctured torus has a
figure-eight spine with
two generators. Filling the puncture kills the boundary commutator and leaves
the abelian period lattice. This offers a possible route from decorated
left/right histories to a flattened `(p,q)` period class.

The existing E0 transformations provide relevant but incomplete local data:

\[
X_s:z\mapsto z-s,
\qquad
J:z\mapsto-1/z,
\]

and the scale correspondence `Y_k` already satisfies the exact Baumslag-
Solitar relation used in `0032-exact-e0-mobius-cellular-bridge.md`. Under a
genus-one interpretation, `X_s` resembles a shear or Dehn-twist action, `J`
exchanges period directions, and positive-degree scale correspondences may be
compared with isogenies or Hecke correspondences.

None of these analogies yet proves that:

1. the AEG upper half-plane is the relevant Teichmuller upper half-plane;
2. the E0 routing extends to a canonical multi-hole configuration carrier;
3. a program cut compactifies to a nodal or cuspidal genus-one curve;
4. the computational boundary is the added geometric point; or
5. the prefix bifiltration descends to a double-periodic lattice.

An explicit intertwining construction or a finite counterexample is required.

## 4. From prefix probability to q-series

The first analytic object is not automatically an elliptic function. It is the
halting generating function

\[
Z_U(q)
=
\sum_{U(p)\downarrow}q^{|p|}
=
\sum_{n\geq0}h_nq^n,
\qquad
Z_U(1/2)=\Omega_U,
\]

where `h_n` counts halting programs of length `n`. Finite `(n,t)` truncations
are exact polynomials with computably certified coefficients.

If decorated left and right components have separate prefix costs, use

\[
Z_U(u,v)
=
\sum_{U(p)\downarrow}
u^{\ell_L(p)}v^{\ell_R(p)}.
\]

This gives a bivariate partition function and a concrete place to test the
proposed `(p,q)` structure. Double indexing alone is not ellipticity. Promotion
to a theta, sigma, or elliptic object requires at least:

1. a lattice-valued index attached canonically to checked program structure;
2. a quadratic form or cocycle controlling prefix cost;
3. a transformation law under the candidate period group;
4. compatibility with `X`, `Y`, `J`, grafting, or the relevant isogeny
   correspondences; and
5. a statement of which intensional data survive periodization.

A generic universal prefix grammar will not satisfy these conditions. Failure
of modularity is an informative expected result, not an implementation error.
If a modular shadow exists, theta or sigma functions are better initial
carriers than the even, fully periodic Weierstrass `wp`, because
quasi-periodicity can retain an orientation-sensitive cocycle. Objectification
may later pass to `(wp,wp')` or another scalar shadow.

## 5. Executable research route

The route should remain narrow: one living research note, small exact tests,
and no stable semantic types until a promotion gate is met. New results,
counterexamples, and changed hypotheses should be appended here rather than
split into governance documents.

| Phase | Exact question | Smallest artifact | Promotion or stop condition |
|---|---|---|---|
| R0 | Can prefix mass be represented without semantic aliasing? | finite prefix-code fixture and Kraft certificate | exact rejection of prefix collisions and duplicate cylinders |
| R1 | Does the two-index approximation behave as claimed? | exact table of `Omega_(n,t)` with halting witnesses | monotonicity, schedule independence, exact supremum on every finite fixture |
| R2 | How does objectification push mass onto fibres? | weighted extension of the finite surreal collision fixture | equal objectified value, distinct histories, auditable aggregated mass |
| R3 | Does prefix composition agree with graft composition? | bounded nested-call fixture with self-delimiting frame codes | additive code cost or an explicit residual explaining its failure |
| R4 | What is theorem and what is executable evidence? | short proof of the effective-cut obstruction plus bounded regression tests | no empirical test presented as a proof of undecidability |
| R5 | Does a useful bivariate generating function emerge? | exact truncated `Z(u,v)` from checked histories | stable coefficient meaning under declared code and observer changes |
| R6 | Is there a canonical map to the E0/elliptic candidate? | finite lattice/intertwining table or checked counterexample | a commuting law for `X,Y,J` and grafting, or a precise no-go witness |

### 5.1 First finite fixture

Begin with a deliberately nonuniversal deterministic prefix machine. For
example, choose a small self-delimiting grammar whose accepted programs
perform a bounded subset of Adva arithmetic and whose evaluator can return
`Halt(value)`, `Running`, or `Rejected` under a step budget.

For every accepted word up to a declared length:

1. check prefix-freeness exactly;
2. retain the word, parse, source identity, and execution trace;
3. compute cylinder weight as an exact dyadic rational;
4. record a halting witness when available;
5. compute every `Omega_(n,t)` without floating point;
6. push terminating mass through a declared objectification;
7. compare enumeration schedules and assert identical finite results.

This fixture calibrates the data model. It makes no randomness,
noncomputability, universality, or geometric claim.

### 5.2 Research-local data, not stable API

The first experiment needs only research-local records conceptually equivalent
to:

```text
PrefixWord
PrefixFreeWitness
HaltingWitness { word, step_count, trace }
DyadicMass { numerator, exponent }
OmegaApproximation { max_length, step_bound, mass, witnesses }
FibreMass { observer, objectified_output, contributors, mass }
```

Rust remains authoritative for checked programs, source and occurrence
identity, histories, cuts, and objectification witnesses. Python may enumerate
finite fixtures, form exact `Fraction` values, and analyze generating
polynomials, but it must not reconstruct semantic identity or infer halting
certificates from matching output values.

The likely first executable location is a bounded Python research test beside
the existing exact surreal and E0 calibrations, backed by Rust-checked IR. Do
not add a public `Omega`, probability, elliptic, or compactification type at
this stage.

### 5.3 First implementation slice

The smallest useful code change after this note is one test module containing
only R0--R2:

```text
tests/python/test_prefix_omega_boundary.py
```

Its acceptance criteria are:

- all masses use exact dyadic arithmetic;
- the codebook includes a machine-readable prefix-free certificate;
- every contribution to finite halting mass has a bounded execution witness;
- `Omega_(n,t)` is monotone in both indices;
- two enumeration schedules produce the same table;
- the existing surreal-form collision becomes a fibre with two separately
  auditable contributors;
- the total finite mass satisfies Kraft's bound;
- the test language avoids claiming that a finite fixture realizes Chaitin
  randomness or proves undecidability.

R3 and later phases should be separate code changes, but their conclusions
should return to this note.

## 6. Main red-team questions

1. **Machine dependence.** Which parts survive a change of universal prefix
   machine: a number, a Solovay degree, a randomness class, or only a measure
   class?
2. **Intrinsic code.** Is prefix length native to the program geometry or an
   imported serialization cost? A useful AEG probability theory needs a
   certified relation between code cost and program construction.
3. **Birthday versus runtime.** Can birthday be derived from cut construction
   while runtime remains a separate causal filtration, or are we assigning
   both notions after the fact?
4. **Two branches.** Do `L` and `R` represent halted/nonhalting information,
   two oriented geometric leaves, lower/upper approximations, or different
   roles at different layers? These readings must not be silently identified.
5. **Singularity category.** Is the completion naturally a domain-theoretic
   noncompact point, a measure boundary, a nodal curve point, a cusp, or a
   stacky/orbifold point? A map between categories is required.
6. **Periodicity gap.** What law turns the bifiltration into a period lattice?
   Without it, an elliptic function is only an analogy.
7. **Probability versus residual.** Does fibre mass provide useful structure
   beyond the exact residual, and which observer operations preserve it?
8. **Composition.** Can a self-delimiting code make prefix cost compositional
   under nested grafting without erasing shared substructure?

## 7. Near-term decision rule

The research has earned its next step if R0--R2 can be completed with exact
dyadic arithmetic and existing checked identities while exposing at least one
nontrivial fibre law. It has earned geometric expansion only after R5 produces
a stable lattice-indexed coefficient system and R6 supplies an intertwining
law or a sharp obstruction.

Until then, the defensible core is:

\[
\boxed{
\text{prefix-free program forms}
\longrightarrow
\text{Kraft semimeasure}
\longrightarrow
\text{objectification fibre mass}
\longrightarrow
\text{Omega-type one-sided completion boundary}.
}
\]

That core already explains why a finite machine cannot symmetrically complete
both sides of the cut. The elliptic and compactification pictures remain
high-value hypotheses whose exact content will be decided by the finite
intertwining experiments, not assumed in advance.
