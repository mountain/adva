# Research 0164：保留库表征差异的三语言 Quine 接力

日期：2026-09-09。状态：完成首次有限闭环及一次发布前复核，各通过七项对照。
方向与问题：Mingli Yuan。构造、实现和本地核验：assistant。

## 问题与实际完成范围

构造 Python 程序 `p`、Rust 程序 `q` 和 adva-lisp 程序 `r`，使

```text
Python(p) = q
Rust(q) = r
ByteObservation(Adva(r)) = p
```

三处等号都按完整源码字节解释，包含末尾换行。每个成员输出下一种语言的
程序；这不是说三个成员分别打印自己的源码。

传统源码接力的参考是 [Quine Relay](https://github.com/mame/quine-relay)。
本实验独立编写两个模板，没有复制该项目代码。

现有 PSC0 能表达闭合有限数值输出，缺少字符串、打印和一般自解释。
因此最后一条边明确包含一个研究用字节观察器：Rust 调用现有解析、链接、
编译、验证和求值 API，只把 `0..255` 内的整数结果逐个写成字节。
观察器不包含 Python 模板，不读取预期 `p`，也不解释 Quine 的构造方法。
`r` 是现有内核可以执行的普通程序。

此输出边界独立于 `adva run` 的小规模 JSON 配置；原命令的限制完全保留。
没有新增 Lisp 运算符、字符串语义、原生解释器、稳定反馈或程序等同规则。

## p 与 q 的对应怎样产生 r

取有限 Python 构造体 `A`、有限 Rust 构造体 `B` 和上述上下文 `C`。
用双方均可表示的十进制字节数组 `N` 引用它们。

`p = P(A,B,C)` 由三个 Python 数据绑定和构造体 `A` 组成；
`q = Q(A,B,C)` 由三个 Rust slice 绑定和构造体 `B` 组成。

`A` 写出 Rust 绑定并展开 `B`；`B` 写出 Python 绑定并展开 `A`，在内存中
重建 `p` 后，才把这些字节编译成 `r` 的有限表达式。无需把“包含整个自己
的字符串”无限嵌套进去，也没有读取自身文件或调用源码反射。

这里给“对偶力量”的候选操作化是**相互引用与展开**：一侧把另一侧的构造体
当作数据，另一侧保留反向重建所需的数据。它得到一个可检查的源码固定点。
这还没有证明一般 Adva thread dual、`D*`、观察器拉回或范畴论对偶。

## 库中的见证确实参与了构造

Rust 用同一个有限账户分别重新加载两份 `epoch-0001`，确认选定见证的两侧
为 `2*x` 与 `x+x`，并在 `x=1..8` 上逐一调用现有 guarded reuse。
两个上下文中的 `x=0` 都被拒绝。输入保持在现有接口的 `-8..8` 范围内。

对于每个字节 `b`，`q` 选择

```text
u = (b mod 8) + 1
v = b - 2*u
```

随后生成普通 Lisp 表达式 `(add (add (copy u)) v)`，其中变量位置直接替换
为数值字面量。`r` 使用库见证的加法表示；其值为 `u+u+v=b`。
所有中间值都是当前 f64 可以精确表示的小整数。这个有限事实不增设一般
整数标量，也不把研究见证升级为稳定 IR 的等式 cell。

`r` 是无输入的常量构造，来源分区为空。显式 copy 节点和各次运算仍保留在
完整程序图和历史中；没有为常量或库角色虚构语义来源。

## 探索路径能否丢弃

明理随后提出这个问题。必须区分**寻找见证的路径**和**见证所描述的程序
自身的历史**。后者在 Adva 中可能是语义对象的一部分；前者未必都需要成为
每次复用的输入。

若最终见证 `W` 连同显式前提 `A` 可被独立检查，`Check(A,W)` 不再依赖搜索
日志，那么使用者不必重走全部探索路径。可复用的是这份足够检查的内容。
但若某项结论还依赖候选覆盖、失败反例、假设来源、实际花费或人类接受，
相应信息必须留下，或被压缩成足以复查那项结论的记录。

本例提供三种不同的问题：

1. **是否闭合？** 保存 `p/q/r`、输出约定、运行依赖和可重放检查，便可重新
   回答。第一次链接器的全部诊断文本不是重新验证闭环所必需的输入。
2. **为何选择这个 r？** 库的固定版本、倍增见证、非零条件和表示选择仍是
   解释这次构造的材料。只留下恢复出的 `p`，无法区分加法与 scale 两条构造。
3. **这次探索付出了什么代价？** 失败轮的发生及耗用不能省略，否则会把
   成功路径的费用冒充整个探索的费用。详细日志可以研究如何压缩，费用与
   失败性质仍须保真。

因此，路径可否丢弃应由要保留的可回答问题决定。一个“足以复核结果的见证”
可能比全部探索史小得多；它也可能不够支持关于发现过程的结论。当前实验
合同要求保留失败和残余，本轮没有删除任何探索记录，没有实现原生 drop、
free 或忘却操作。下一步可以研究最小可复查记录，但不能由源码闭环直接
推导出删除历史的权限。
