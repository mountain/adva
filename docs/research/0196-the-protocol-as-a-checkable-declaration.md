# 0196 — 把协议写成可检验的声明：六条判据，五过一不过

Status: bounded exact check, research-only. Evidence:
`experiments/protocol_declaration/evidence.json`（声明文件与检查器同目录）。本轮执行的是 0195
结尾建议里的 **(a′)**：把方向那一行协议从**提案**变成**可检验的声明**。

## 1. 声明文件（`protocol.json`，可读可改）

| 条款 | 声明 |
| --- | --- |
| **侧边** | 三个侧边，等分；规则 = **拉平（leveling）**，即"在步池允许的范围内给最浅的一侧加深"；等分是该规则的**齐平情形** |
| **准备金** | 声明值 **1/100**；规则 = **按价格（priced）**，即"使已解出质量最大的那个量" |
| **连接** | 价格来源 = **0195 实测**（孤立链接 533 字节 + 序号位数；接链另加 64 字节前任读取）；换算 **8 层步 / 实测单位**（声明） |
| **钥匙一半** | **unmeasured**（本机无 ed25519 后端；没生成也没验证签名） |
| **回推** | 触发条件 = **保留工具的判定字段**（`tamper-check` 的 `prev_anchor_match`），不是转述 |
| **层级推进** | 接上一条链接抬高天花板一层；解出一层使剩余质量**减半** |

声明里明写 `checks_required` 六条；检查器**逐条算**，并核对"声明的判据集合"与"实际执行的判据集合"**完全一致**。

## 2. 判定：**5 过 / 1 不过**

```
[pass] 分配在整步上精确闭合
[pass] 声明的侧边分法是该步池下的拉平分法
[fail] 声明的准备金是声明连接价格下的定价准备金（或声明必须写明差距）
[pass] 钥匙一半已测、或带着附加量/界
[pass] 回推触发条件点的是保留判定字段
[pass] 接上一条链接抬高天花板一层、解出一层使剩余质量减半
```

**唯一不过的那条，带数字**（预算 1000 层步、换算 8）：

| 量 | 声明（1%） | 定价 |
| --- | ---: | ---: |
| 准备金 | **10 步** | **225 步**（= 9/40 = **22.5%**） |
| 买到层级 | **1** | **26** |
| 已解出质量 | **3/4** | 134217727/134217728 |
| **残余质量差距** | — | **33554431/134217728 ≈ 0.250** |

也就是说：**按实测的连接价格，声明的那 1% 会让四分之一的空间永远解不出来** ✓。
检查器还把"**怎样才能通过**"写在证据里：**要么链接便宜到 1% 就是定价值，要么把声明值改成定价值**。

## 3. 其余五条为什么过（以及它们各自在说什么）

- **分配闭合**：整步规则下 `33/33/33 + 余数归准备金` 精确填满预算，无舍入；
- **侧边**：检查器**用穷举**复核"拉平"确实是该步池下的最优（不是信 0193，而是**同一轮里再算一次**）；
- **钥匙一半**：这一条**过的是"义务"**，不是"舒适"：声明必须一直写 `unmeasured`，
  **一旦在没有测量的情况下写成 measured，检查器就判不及格**（那等于把未知量定价为零 ✗）；
- **回推**：点的是**保留判定字段**而不是自己的转述；
- **层级推进**：用的是 0191 的层质量，剩余质量逐层减半。

## 4. 这一轮记录在案的错误

- 第一版检查器的六条判据**文案**与声明文件里的六条**不完全一致**（两条措辞有差），
  被"**声明集合 = 执行集合**"这条检查**当场拦下** ✓——这正是那条检查存在的理由：
  **声明与实际执行的东西必须是同一份**，否则"通过了"就只是在通过我自己写的字。
- 除此外本轮没有引入浮点：平方根用**整数**、除法取整用**整数**。

## 5. 本轮**没有**主张的

- 检查器**不论证最优性、也不裁定协议**：它只报告**哪一条声明与测量相矛盾**；
- 连接价格经过一个**声明的换算**（8 层步/实测单位）→ 那条不及格是**在该换算下**不及格；
  换算是声明参数，**不是测量**；
- **钥匙一半仍未测** → 整个协议仍是**纯证书定价**；
- **没有**读取或改写任何保留的锚点/凭据/密钥；**没有**原生改动；
- **三侧张力**照旧未化解（`TriadicObserverPolicyV0` 禁止读成三台独立计算机，见 0192 §8）：
  本声明为了可算，把三侧当**额度持有者**。
