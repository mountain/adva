## 一个完整可检查的恒等式

令六个有序齐次点为 (p_i=(x_i,y_i,z_i))，固定列顺序，定义

\[
F(p_1,\ldots,p_6)=\det
\begin{pmatrix}
x_1^2&y_1^2&z_1^2&x_1y_1&x_1z_1&y_1z_1\\
\vdots&\vdots&\vdots&\vdots&\vdots&\vdots\\
x_6^2&y_6^2&z_6^2&x_6y_6&x_6z_6&y_6z_6
\end{pmatrix}.
\]

以叉积实现两点连线与两线相交，下标模 6：

\[
\ell_i=p_i\times p_{i+1},\qquad
q_1=\ell_1\times\ell_4,\quad
q_2=\ell_2\times\ell_5,\quad
q_3=\ell_3\times\ell_6,
\qquad G=\det(q_1,q_2,q_3).
\]

所检查的命题是 **整数多项式恒等式 (F=G)**。
这条恒等式是已有成果；文献 [Variations on Pascal's Theorem, §1.1](https://arxiv.org/html/2411.07638v1)
明确给出六阶共圆锥判定与三阶入射判定的同一性。本次贡献是项目中的
可重检实现、AEG 接口检查、反例和成本实验，不主张发现新定理。

检查器在整数多项式环中，分别用行列式定义的排列展开构造 (F)，
用九个叉积和一个三阶行列式构造 (G)。两边的规范式各有 720 个非零项，
总次数为 12；逐项相减的结果为零。见证保存整个共同规范式。
这是有限符号运算给出的恒等式证据，覆盖任意代入；数值样本不承担这一证明。

可信计算基包括 Python 整数运算、稀疏多项式运算和本文件定义的表达式。
它尚未导入 Rust、Lean 或 Metamath 内核。重检会重新构造两个表达式，
比较完整结果与固定问题绑定的文档；仅修改“残差为零”字段不能获得接受。

在 \(\mathbb Q\) 或 \(\mathbb R\) 上，(F=0) 等价于六点满足某个非零二次齐次式，
因为六阶矩阵此时存在非零核向量。在六点互异且无三点共线的范围内，
该圆锥不能退化为两条直线，交点也有定义；于是 (F=G=0) 给出 Pascal 共线性。
相反，任意输入上的标量 (F=G=0) 不自动保证这个几何范围：重复点可以使所有叉积为零。
实现单独检查几何侧条件，并允许合法的无穷远点。

可手算的正例是

\[
p_{i+1}=(i,i^2,1),\quad i=0,1,\ldots,5.
\]

它们在 (x^2-yz=0) 上，产生

\[
q_1=(12,12,6),\qquad q_2=(18,42,6),\qquad q_3=(30,150,0).
\]

三者行列式为零，第三个交点在无穷远。只把最后一点改成 ((5,26,1))，
得到 (F=G=288\ne0)。这一反例排除了省略共圆锥条件的错误问题表述。

## 与 AEG 的射影背景怎样连接

本次核对的 [AEG paper-0 射影统一章节](https://github.com/mountain/aeg-paper/blob/609ac96b4df802a8a4a6c4079c43c2fae466bc3a/paper-0/sections/06-projective-unification.tex)
把非退化单孔算术段表示为 \(M\in\mathrm{PGL}_2(K)\)，作用在 \(\mathbb P^1(K)\)。
Pascal 问题属于 \(\mathbb P^2(K)\)。一个足够用的连接是

\[
\nu([s:t])=[s^2:st:t^2].
\]

它把射影直线参数化为圆锥 (xz=y^2)。令

\[
M=\begin{pmatrix}a&b\\c&d\end{pmatrix},\qquad
\rho(M)=\begin{pmatrix}
a^2&2ab&b^2\\ac&ad+bc&bd\\c^2&2cd&d^2
\end{pmatrix}.
\]

精确展开得到

\[
\nu(M[s:t])=\rho(M)\nu([s:t]),\qquad
\det\rho(M)=(ad-bc)^3.
\]

检查器单独对六个符号变量验证这四个多项式残差全部为零。
因此 (ad-bc\ne0) 时，AEG 的这类射影作用能相容地作用于该圆锥；
缩放 (M) 只把 \(\rho(M)\) 缩放其平方，故射影类也有定义。
这给出一个具体交换接口，不需要先建立所有知识空间的共同几何。

这里的 \(\rho(\mathrm{PGL}_2)\) 保持指定圆锥，并不等于任意 \(\mathrm{PGL}_3\)。
普通算术中间分母为零，与射影延拓后到达无穷远，仍须区分。
这些标量／射影恒等式不授权合并 Adva 原生历史、来源或 occurrence，
也不建立目前尚未实现的证明运输 API。

## 成本证据与方向判据

速度基线使用带行交换与精确除法的六阶
[Bareiss 整数消元](https://www.ams.org/mcom/1968-22-103/S0025-5718-1968-0226829-0/)。
720 项排列展开只用于证明，不拿来制造缓慢的计时基线。

固定批次有 320 个输入：192 个分布于 16、64、256 位的整数坐标输入，
64 个含无穷远点并经过平面变换的圆锥例子，以及 64 个重复点退化例子。
退化例子计时比较的是完全相同的标量查询，不把它们冒充 Pascal 几何实例。
每条路线都做输入检查、精确求值、结果序列化与散列。两条路线全部输出一致。

Python 3.12.13、本机同一进程中，七轮交替先后顺序的观测：

| 测量项 | 本次结果 |
|---|---:|
| 六阶 Bareiss，每批中位耗时 | 21.185153 ms |
| Pascal 入射计算，每批中位耗时 | 3.935299 ms |
| 上述中位耗时比 | 5.3834 |
| 一次性见证生成、序列化、重新验证、散列 | 51.742723 ms |
| 按本次中位耗时摊销所需完整批次 | 3 批，即 960 个输入 |
| 三批基线成本 | 63.555459 ms |
| 三批入射计算，加一次性检查成本 | 63.548620 ms |

第三批的计算余量仅 0.006839 ms；所以“3 批”是这次观测的计算值，
并非稳定性能保证，实际部署必须重新测量并留余量。原始七轮耗时已保留。
以上口径排除导入、输入生成、磁盘 I/O、研发、集成、客户验收与未来维护。
这些排除项使它不能直接成为企业投入的收益数字；峰值内存也未在本次测量。

这是两个明确 Python 实现的比较，不能声称优于所有常规算法。
已经采用同一 Pascal 恒等式的常规实现，可以使用同一个短计算；
相对这种实现，本见证添加了一次性检查成本，没有证明额外计算优势。

令 (H) 为一次性构建和验证成本，(C_0) 为原路线每次完整成本，
(C_1) 为复用路线每次完整成本，(N) 为实际重复次数。
满足同一正确性与交付约束后，局部成本方向为

\[
\Delta(N)=N(C_0-C_1)-H.
\]

只有 \(\Delta(N)>0\) 才有严格摊销收益。如果依据有保证的同单位界：

\[
H\le H_+,\quad C_0\ge C_{0,-},\quad C_1\le C_{1,+},\quad N\ge N_-,
\]

则可用充分条件

\[
C_{0,-}>C_{1,+},\qquad
N_-(C_{0,-}-C_{1,+})>H_+.
\]

只要这些假设成立，收益下界即为右式减去 (H_+)。代码用非负整数成本刻度
检查严格不等式，缺少界则返回 `Unknown`。本机耗时的最大／最小值不被当成
未来有保证的界。本次企业成本与任务量留空，因此企业决策结果明确为 `Unknown`。

在知识空间中，这是以“任务—表示—证明—复用”为节点关系的**局部差分方向**；
无需先赋予整个空间黎曼度量，也没有定义物理能量或连续梯度。
决策理论提供有约束的成本比较；现实测量提供其中的数值与用途。

建议把“带证据的数学计算／证明组件”作为一个小规模产品试验方向。

> 在明确任务边界中，携带等价性见证、适用条件、成本记录与摊销判据的复用候选方向。
