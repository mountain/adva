## 3. 自算的

**数据来源**：`experiments/golden_ratio/calibration.py`（sha256 记入证据）中 `golden_rectangle_checks` 里的**字面** `rectangles` 赋值，用**受限 AST 解码器**读取，**不执行**历史模块（沿用上一轮审计的做法）。解出的三块是坐标平面上的矩形板：`z0: |x|≤1, |y|≤φ`、`x0: |y|≤1, |z|≤φ`、`y0: |z|≤1, |x|≤φ`。

**方法**：链接数用**一条轮廓线与另一条的张成矩形求代数交**（精确 Q(√5) 算术），这与保留轮用的"投影交叉计数"是**不同的算法**，所以它是一次交叉核对，而不是重放。

**结果**：

| 成对 | 本轮（正向／反向） | 保留轮的投影计数（有向和） |
| --- | --- | --- |
| z0 ∥ x0 | 0 / 0 | 0 |
| z0 ∥ y0 | 0 / 0 | 0 |
| x0 ∥ y0 | 0 / 0 | 0 |

- **三重交点的符号 = +1**（三种循环次序同号，反序翻转），与保留记录的 +1 一致；
- 三个填充矩形**只在原点相交**（由代码检验，不是目测）；
- 这些都对上了：**两两不扣、三体相缠** ✓

## 4. 剪断分析（本轮的新内容）

对三种剪法各算一遍存活的一对：

| 剪掉 | 存活对 | 存活对的链接数 | 分离判据 | 结局 |
| --- | --- | ---: | --- | --- |
| z0 | x0, y0 | 0 | 三条判据全部 inconclusive | **Unknown** |
| x0 | z0, y0 | 0 | 同上 | **Unknown** |
| y0 | z0, x0 | 0 | 同上 | **Unknown** |

三条分离判据各自带上结论与理由：包围盒**相交**（不足以判分离）、**找不到分离平面**、**两张张成曲面确实相交于原点**（但分离也可以用球面，所以这什么也不决定）。

**为什么会是 Unknown**：存活对的成对链接数为 0，而链接数对"是否可分"是**必要不充分**的（0 什么都不决定）；本轮的算力就到这里，于是如实报 `Unknown`，**不猜**。

**一个结构性事实**（记为计算的性质，不是定理）：链接数的计算**只用到存活的两条曲线**，所以剪掉第三环**不可能**改变它——这不是"侥幸没变"，而是这一计算的定义域所致。

## 5. 你要的那条对照：成对链接 vs 三重链接，在"抗剪"上

| | 剪断第三环之后 |
| --- | --- |
| **成对链接** | **存活、且能判定**：它是存活对的不变量，本轮在每次剪断后重算；非零即可证"不可分"。对照构型：Hopf 式相扣的两块（`lk = −1`，两个方向一致），把第三个旁观方块剪掉后**仍为 −1**，所以这一对**抗剪**。反向对照：两块平行方块 `lk = 0` 且有**显式分离平面**，被判为可分。 |
| **三重链接** | **不是被藏起来，而是失去了定义域**：Milnor 三重链接不变量定义在**三**分量的链环上；剪断之后只剩两条闭曲线加一条弧，它无从谈起。而存活对的成对链接数在保留构型里**恒为 0**，所以没有任何本轮算得出的东西接替它。 |

一句话：**这一刀恰好切掉了携带缠绕的那一项**；留下的那个不变量在这三对上都读作 0，于是"剩下两环还相扣吗"在本轮的工具下**无法判定**。

## 6. 两个副产品

- **有理比同伴**：把 φ 换成 **3/2**，三块板的成对链接数同样全为 0、三重交点符号同样为 +1。所以让这一族解链的是"**比值大于 1**"，**不是 φ 的特别**——这与保留轮自己的告诫一致（"a unit invariant here is not evidence of uniqueness of the golden ratio"）。
- **保留的同心正交方块同伴**（`m = 1, t = 1, μ = 0`，**引用不重算**）：它与黄金矩形**三重交点计数相同**却 μ = 0，这正是"计数不是不变量"的对照——也是第 5 节里为什么必须区分两种链接的原因。

## 7. 什么才能判定那个 Unknown

1. 存活二元子链环的 **Alexander／Conway 多项式**（从一张图算起；非零即可证不可分）；
2. 一个**显式的分离球面**，或一条把两分量分开的**同痕**；
3. 保留构型到**标准 Borromean 环**的等距同痕——有了它，第 2 节里那条经典陈述才能转移过来。

**三件本轮都没有做。**
