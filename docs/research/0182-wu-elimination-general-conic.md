## 1. 证书本身

| 量 | 值 |
|---|---|
| 假设 `H`：六点共一条圆锥曲线（`6×6` 单项式行列式） | **720 项**，8 次 |
| 结论 `C`：三对对边交点共线（三叉积的行列式） | **720 项**，8 次 |
| **伪余式 `prem(C, H, y6)`** | **恒为 0** ✓ |
| 非退化条件 = `H` 在 `y6` 上的首系数 | **120 项**，6 次 |
| 结论是否恒为 0？ | **否**（所以假设是必需的，定理不是空的） |
| 伪造对照（换掉一个顶点）的余式 | **≠ 0** ✓ 被检出 |
| 随机精确实例（随机有理圆锥 + 六个有理参数，3 例） | 共线行列式 **恰为 0, 0, 0** ✓ |

**证书的确切含义**（必须说准）：`prem = 0` 是**伪可除性**，不是理想成员判定——它断言结论在假设簇上**除掉首系数为零的地方**恒为 0。那个首系数（120 项、6 次）就是**非退化条件**，不是可以省略的脚注。

## 2. 两处成本事实（都测了）

1. **行列式方法差两个数量级**。同一批符号行列式：
   - `5×5` 小例：默认的除式法 `bareiss` **1.11 s**，无除法 `berkowitz` **0.070 s**（两者同一多项式，120 项）；
   - `6×6` 圆锥行列式：默认法 **112.5 s**，`berkowitz` **0.62 s** —— 这是**侦察阶段**实测的（该轮不重跑 112 秒的版本，如实标注为侦察数据）。
2. **展开是全部成本，归约几乎免费**：
   - 构建结论 `0.25 s`、构建假设 `0.62 s`、**伪余式归约 `0.80 s`**。

也就是说：**吴方法的"消元"这一步在这里极便宜，真正贵的是把几何条件展开成多项式**。这一条对任何想在仓库里用它的人都是可操作的信息。

## 3. 与 0181 的关系

0181 用的是**抛物线上**的六点（假设 `y_i = x_i²`，本身就是一条三角链）；这一轮用的是**一般圆锥曲线**（假设是一个不可约的行列式，不是链）。两者互补：

- 抛物线那种"链"的形式，可以走**特征链 + 逐步归约**；
- 一般圆锥这种"单个高次假设"的形式，**只要首系数非零**，一次伪余式归约就够了——这正是吴方法最经典的用法。

## 4. 不主张什么

- **不是原生证书**：外部计算（Python + sympy），不是 Rust 导入、不是派生证书；`adva-library` 的 **Pascal 增长义务仍然 Open**，本条**不**接通它。
- 只对**声明的多项式形式**成立，且**在首系数不消失处**。
- 不主张**理想成员判定**；不主张对 Feigenbaum 线有任何结论。
- 侦察阶段那条"参数化一般圆锥（6 个系数）"的路线**恒等于 0**，但符号展开要 **145 s**，因此**记录为侦察数据、不在本轮重跑**。
