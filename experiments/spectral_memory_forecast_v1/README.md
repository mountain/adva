# spectral memory forecast v1

Original external numerical research, not native Adva authority.
See [Research 0230](../../docs/research/0230-native-background-forecast-and-display-interpolation.md).

`contract.json` preceded the single training launch; `training-receipt.json`
is the outcome. Historical `launch-ledger.json` retains spent fuel. Do not
reuse a different ledger to repeat the same bounded trial. Verification, when
present, has its own pinned contract and one original verification allowance.
The memory attempt was not promoted and its verification was not launched.

These scripts require the exact private input pins and separately installed
xue-study runtime in the contract, plus Python 3.11.15, NumPy 2.4.6 and SciPy
1.17.1. They are not self-contained public replays. Missing inputs give an
explicit Unavailable result, never success. Dependencies and meteorological
source arrays are not vendored into Adva. The public report records aggregate
measurements, provenance facts and hashes only. Large learned artifacts are
separately published with source attribution at climatetensor.io.
