# Observer identity collision

This project-original finite experiment exhausts one three-event fork carrier,
eight exact metadata variants, and all five downsets. It compares event-only,
source-aware, occurrence-aware, and history-aware observation profiles.

Run from the repository root into a new output path:

```sh
python3 experiments/observer_identity_collision/run.py --output /tmp/observer-identity-collision
```

The experiment is an abstract counterexample calibration. It does not import a
Rust-checked Adva carrier, implement a native probe, or issue a certificate.
