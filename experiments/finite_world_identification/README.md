# Finite world identification research package v0

Canonical home: `mountain/adva`, this directory. See the
[research report](../../docs/research/finite-world-structure-identification-v0.md)
for interpretation, results and limitations; `contract.json` fixes the family,
observer interfaces, outcomes, protected distinctions, resource bounds and #26
residual. `worlds.rs` is the Rust producer/receiver and test suite. `evidence.json`
is the exact frozen native output, including every source, compilation artifact,
identity, transition and slice. `attempts.json` preserves the environmental
failure and execution record. `run.py` supervises and checks exact replay.

Run from a checkout with the unchanged locked Rust dependencies:

```sh
python3 experiments/finite_world_identification/run.py --output /tmp/world-id-new
```

The destination must be new. The source is staged only temporarily as an
integration test; no tracked crate source, workspace manifest, lock or historical
certificate changes. The dedicated workflow executes the same route and native
regressions. Scoped export: complete finite family and observer-class evidence,
with no stable native learner authority, new effects, general recovery theorem,
portable certificate admission or specialization. Changed grammar/observer or
checker requires a successor contract and new evidence, not replacement of the
frozen result. Removal of this research directory reverts the experiment without
changing any kernel or consumer. Reuse requires actual replay, not trusting JSON
success flags. Dependency binding and supervision costs are in each fresh output.
