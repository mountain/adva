# Encyclopaedia Demonstrativa

Status: reserved literate-programming corpus; not an active stable-API phase.

This directory is intended for an executable encyclopedia inspired by the
Leibnizian ideal commonly described as an *encyclopaedia demonstrativa*.

Its subjects should not appear only as retrospective summaries. Each tradition
should be allowed to appear in its own problem, vocabulary, notation, paper
form, and executable form. Adva translations are interpretations to be tested,
not claims that Adva has subsumed the original system.

The governing pair is:

```text
paper explains program <-> program witnesses paper
```

## Editorial discipline

1. Preserve the native question and syntax before introducing Adva vocabulary.
2. Distinguish primary source, historical reconstruction, modern
   formalization, and Adva interpretation.
3. Claim equivalence only through explicit translations and stated proof or
   certificate obligations.
4. Record partial and one-way translations, counterexamples, residuals, and
   `Unknown` results.
5. Do not use computational universality to erase differences in computational
   form.
6. Keep experimental reconstructions outside the stable semantic kernel until
   their dependencies and promotion gates are satisfied.

## Provisional first constellation

The first computational studies may center on the convergent formulations of
effective computation around the 1930s:

- Schönfinkel--Curry combinatory logic;
- Church's lambda calculus;
- Herbrand--Gödel--Kleene recursive functions;
- Turing machines;
- Post canonical and production systems.

A later logical constellation may place the Greek and modern European
traditions in genuine comparison with Dignāga and the traditions of
`pramāṇa` and `hetuvidyā`. That work should begin only after the current
logic bootstrap has produced a sufficiently precise object of comparison.

## Shape of a mature entry

A mature entry should eventually contain:

1. the historical problem;
2. the native calculus or argumentative form;
3. a minimal faithful executable reconstruction;
4. a representative source-guided example;
5. an explicit translation into Adva;
6. an inverse or partial translation where one exists;
7. proof obligations, translation loss, and the remaining open frontier.

This file establishes a home and an editorial promise. It does not yet assert
any historical identification, universality theorem, or new Adva semantics.
